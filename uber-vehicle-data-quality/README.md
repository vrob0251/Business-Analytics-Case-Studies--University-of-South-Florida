# Uber Vehicle Data Quality & Modeling

## Business Problem

Uber needed a structured dataset to monitor vehicle inspections, clearance status, customers, and employee sign-offs.

## Objective

Evaluate whether the available dataset could answer the business questions and identify opportunities to improve data quality and structure.

## Analysis Approach

- Reviewed whether the dataset contained the information needed for analysis
- Evaluated assigned data types
- Identified formatting and data-quality issues
- Reviewed date fields for consistency
- Considered how customers, vehicles, employees, and inspections should be related
- Prepared the dataset for exploratory analysis

## Key Data Quality Considerations

- Correct data types
- Consistent date formatting
- Missing or incomplete values
- Duplicate records
- Accurate vehicle and customer identifiers
- Clear inspection and clearance status fields

## Business Recommendation

Standardize and clean the dataset before analysis so vehicle clearance status can be accurately connected to customers, employees, inspections, and expiration dates.

Improved data quality would make reporting more reliable and support better operational and safety decisions.
